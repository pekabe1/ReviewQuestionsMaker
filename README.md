# ReviewQuestionsMaker

A collection of AI prompts for simulating job interviews and generating review questions.

## Available Prompts

| Prompt | Language | Focus |
|--------|----------|-------|
| [.NET Developer Interview Simulation](prompts/dotnet-developer-interview-simulation.md) | English | Technical questions |

## How to Use

1. Open the prompt file that matches the role you want to practice for.
2. Copy the full prompt and paste it into your preferred AI assistant (e.g. ChatGPT, Copilot).
3. Follow the instructions inside the prompt to start the simulated interview.
4. After the interview, the AI will give you detailed feedback and a score for each answer.
